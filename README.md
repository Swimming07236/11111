# 虚实疆界

**Il confine tra reale e immaginario**

本地图文作品网站。页面、PPT 美术、字体、动画和 MP3 标签读取都在本地，不依赖在线歌词接口。首次安装需要下载依赖，安装后可离线运行。

## 启动

需要 Node.js 22 或更高版本，建议使用 Node.js 24 LTS。双击 `start.cmd`，首次会安装缺少的运行依赖；也可以先在此目录运行 `npm install`，再运行 `npm start`。打开 <http://127.0.0.1:4173>，保持启动窗口运行。请通过这个地址访问，不要直接打开 HTML 文件。

章节选择在顶部磨砂栏居中。点击站名回到主页。每次切换先进入短暂黑场，再由各章节的原有美术图层依次浮现，最后过渡到页面。动画右下角“略过”或 Escape 可跳过图层展开。浏览器前进/后退也会切换章节。

美术从用户提供的 `沉沦者的黑流树海PPT模板/沉沦者的黑流树海PPT模板.pptx` 第 4、9、14、18、21 页提取。保留图片裁切、组合位置、旋转、透明度和装饰矢量图形。没有修改原 PPT。模板中的文字和配色样本不属于网页插画，页面使用自己的标题与内容。

`public/assets/chapters/scenes.json` 保存原图层与构图，`public/scenes.js` 定义不同元素的进入方向、延迟和缩放。主页和章节题图使用相同构图，避免转场结束时换成不相关画面。

章节名称保留在入场动画里；页面内保留完整主题美术，通过顶部选中项标识章节，题图上不重复显示标题与副标题。主页的分类说明已放大，并有更完整的章节介绍。边框、分隔线和页脚复用手稿符号与原 PPT 装饰。

## 序章

- 首先显示独立的纯黑起始页，中央以电脑像素字体显示「是否开启生命跃迁？」。启动按钮由多层环形刻度、二进制、眼形几何与流动电路构成，悬停时放大、高亮；下方以较小红字提示「启动程序会产生声音，请保证设备处于恰当环境中」。点击后淡出，开始加载。音乐列表准备好前按钮暂不可点击，停留期间不播放、不推进加载。
- 点击「开始」后随机选择一首音乐，从静音随 SANITY 下降逐渐增强，在 SANITY 到 0 时达到用户设置的音量。星图、黑洞与首次主页入场期间保持同一首歌。
- 纯黑背景，复杂点线多面体从开始就是亮黄色，持续旋转、轻微振动。白色从一个固定顶点沿网格传播，最终覆盖整体；颜色边界随三维旋转移动。
- 双侧进度条向中央汇合，与中央 SANITY 数字错开排布。
- SANITY 从 999 按先快后慢的曲线递减，90% 时到 0，100% 变为红色加粗的 -1 并短暂停留。三位、两位、一位数字依次增大。
- 加载文字依次为：正在关闭认知滤网、正在关闭现实稳定锚、正在建立超距连接、红色动态乱码。最后一段不加粗。
- 加载完成后展开星图与固定的手稿风格站名。意大利语采用模板附带的 Voynich 字体，字号为中文的 85%，窄屏可自然换行；中文采用可读的楷书字形。停留时不再变换字体。保留偶发代码错位、光标视差与缓慢自主漂移。
- 点击画面、入场符号，或按 Enter/空格，触发黑洞吞噬。之后留一小段黑场，再播放玻利瓦尔肤层的入场动画。
- 右上角可暂停音乐并回到起始页，重新点击后重看序章。系统开启“减少动态效果”时使用较短的淡入淡出，关闭旋转、振动、快速乱码和星图持续移动。

## 替换内容

左侧音乐抽屉：悬停展开、移开收起，点击可固定；手机点击入口展开。支持封面、标题、播放/暂停、切歌、播放进度和音量。仅在最初启动时随机选曲；切换章节、返回主页均延续当前播放，不重新选曲、从头重播或改变手动暂停状态。把 MP3 直接放进 `public/assets/music/` 后刷新，或点击「↻」，即可自动发现并读取内嵌标题、歌手、专辑、封面、SYLT/USLT/LRC 歌词。同步歌词随播放高亮并滚动，点击歌词可跳转；普通歌词作为文本显示，没有歌词时给出明确提示。也可点击「添加 MP3」选择本机文件临时试听，文件不上传，刷新后临时歌曲不保留。详细说明见《内容编辑指南.md》第六节。音频通过本地服务按需分段读取，支持拖动进度。

`public/content.js` 的 `musicDefaults.home` 目前为 `'random'`，只控制首次启动时的选曲。章节指定曲目已取消，原 MP3 文件仍在歌单中。音乐开始后仍可手动控制，歌曲结束按歌单顺序继续。

根页面已预留稳定的滚动条位置，章节过场按容器宽度对齐，避免动画结束解除滚动锁时内容横向跳动。

编辑 `public/content.js`：

详细操作、字段说明及可复制的作品条目见根目录的《内容编辑指南.md》。

| 配置 | 用途 |
| --- | --- |
| `title` / `italianTitle` | 中文与意大利语站名 |
| `music` | 可选的音乐配置；每项只需 `src`，`title`、`cover` 可覆盖内嵌信息。配置列表之外还会自动加入音乐文件夹中的 MP3 |
| `musicDefaults.home` | 最初启动时的音乐；`'random'` 随机选择，也可填写完整文件名或用 `''` 关闭启动播放。章节不参与选曲 |
| `home.intro` | 主页介绍，每个字符串显示为一个自然段 |
| `navigation` | 四个章节的顺序、名称、颜色；`description` 是分类，`intro` 是章节内短简介，`overview` 是主页的完整章节介绍 |
| `loadingMessages` | 四段加载文案；最后一段在常规动态模式下变为乱码 |
| `introDuration` | 加载时长，默认 8000 毫秒 |
| `introEffects.glitchIntervalMin/Max` | 星图代码错位间隔，默认 8000–14000 毫秒 |
| `introEffects.starDriftSpeed` | 星图漂移速度，默认每秒 0.65 像素 |
| `introEffects.starDriftIntervalMin/Max` | 漂移方向周期，默认 3–6 分钟 |
| `works` | 图片、标题、摘要、正文、分类与留言开关 |

当前六篇图文是示例。把图片放在 `public/assets/`，修改作品的 `image` 地址。`paragraphs` 中每个字符串是一段正文。作品 `id` 应唯一，只使用小写字母、数字和连字符；更换标题时保留 ID，已有留言才会继续关联。更改内容后重启服务并刷新页面。

每篇作品设置 `commentsEnabled: true` 可开启留言。访客只需名字与内容，所有留言由服务统一保存到 `data/comments.json`，刷新和重启后仍在。备份该文件即可备份留言。此文件不会通过静态网页公开。

## 本地访问范围

默认仅本机可访问。需要局域网访问时，在 PowerShell 设置 `$env:HOST = '0.0.0.0'` 后运行 `npm start`。其他设备通过本机局域网 IP 和端口 `4173` 访问；保持服务运行并允许本机防火墙访问。本项目尚未部署公网。

## 检查与素材生成

运行 `npm run check` 和 `npm test`。`music-metadata` 负责标签读取；浏览器版解析器已经打包在 `public/vendor/`，运行时无需外网。升级该依赖后运行 `npm run build:music` 更新浏览器解析器及随附许可证（需要安装开发依赖 esbuild）。

开发时可运行 `scripts/extract-chapter-art.py` 重新提取原 PPT 图层（需要 Python、lxml、Pillow、NumPy）。`scripts/build-title-assets.py` 从模板附带的 Voynich 字体和本机 Windows 楷体生成两个本地字体子集（需要 fonttools、brotli）。重新修改中文站名时同步生成字体；普通作品正文和介绍文字不需要生成字体。公开部署前可将字体替换为许可适用的字体。

起始页中文像素字体使用 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) 2026.09.25 的 12px 简体中文等宽版，本地文件为 `public/assets/fonts/pixel-zh.woff2`；OFL 与上游许可证保存在同目录的 `fusion-pixel-licenses/`。字体仅用于起始页，后续手稿站名和章节字体独立保留。
